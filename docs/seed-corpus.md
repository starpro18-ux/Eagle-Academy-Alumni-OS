# Eagle Academy seed corpus

The initial local source set supplied for product discovery is:

- EAAA General Meeting Docs (March 2026 - August 2026).pdf
- EAAA Strategy Session Meeting (FY 25'-26').pdf
- Engagement Calendar_EAAA.xlsx
- Bylaws - Eagle Academy Alumni Association v3 (1) (1).pdf

These files are not committed to GitHub. They should be uploaded through the product's protected source-ingestion flow after the separate Supabase project is selected.

The first ingestion run should preserve:

- original filename
- provider or upload source
- source URL or storage path
- file hash
- version
- created and modified timestamps
- extraction status
- reviewer
- citations used in generated artifacts

The source set is a starting point, not ground truth. Leadership should approve the canonical bylaws, active calendar, and current organizational structure before they are used for recommendations.
