# Command center

The authenticated command center is available at `web/app.html`.

It is the primary starting point for the connected product. It provides:

- a single navigation shell for the protected surfaces;
- organization-scoped pipeline counts;
- recent sources and commitments;
- a momentum indicator based on live records;
- a context-aware next action;
- clear shortcuts into ingestion, review, and event tracking.

The command center is read-only. Actions link to the existing protected workflows, and all browser reads continue to use the Supabase publishable client under RLS.
